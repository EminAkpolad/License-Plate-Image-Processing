# Plaka Veriseti Üzerinde Görüntü İyileştirme ve Nesne Analizi

Bu proje, MATLAB kullanarak plaka görüntüleri üzerinde gürültü temizleme, kontrast artırma ve morfolojik analizler gerçekleştiren bir dijital görüntü işleme uygulamasıdır.

## 🛠 Kullanılan Teknikler
- **Gürültü Giderme:** Median vs. Average Filter karşılaştırması (Salt & Pepper Noise).
- **Görüntü İyileştirme:** Adaptif Histogram Eşitleme (CLAHE).
- **Morfoloji:** Closing ve Hole Filling (Nesne bütünlüğü sağlama).
- **Analiz:** Segmentasyon sonrası beyaz nesne alan (Area) hesabı.
